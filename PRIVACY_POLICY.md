# Privacy Policy for API Mock Extension

API Mock Extension does not collect, store, or transmit any personal user data.

## Data Storage
All mock rules, headers, and response payloads are saved locally on the user's device via `chrome.storage.local`. No data ever leaves your browser.

## Third-Party Services
The extension does not use tracking, analytics, telemetry, or external servers.

## Contact
For any privacy questions, please contact the developer via the official web store support link.
